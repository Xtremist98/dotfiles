## Current state (2026-09-16) — `lutgen-everpuccin` rewritten: precise palette mapping like lutgen's own palettes
- **Old script was broken:** it used Gaussian-RBF `-R -s 128 -n 16 -l 12` + a 60/40 original blend → every hue got washed/pale (sun→(217,196,148), flower→(208,153,137) instead of palette colors). Root causes: (a) `-R s=128/n=16` spreads anchor influence too wide, (b) the palette was a scrambled 16 that included `#FAF4ED` etc diluting darks, (c) the 40% blend erased the LUT.
- **Native `lutgen apply -p rose-pine` (default algorithm!) snaps EXACTLY** to palette colors (sun→`#f6c177`, flower→`#eb6f92` byte-exact) because it uses the default algo (NOT `-R`). That default algo has `-l 10` default; **`-l 16` is what makes darks byte-exact** (black `(0,0,0)`→`(24,27,27)` = `#181B1B`; the built-in `-l 10` leaves darks ~+4 off).
- **Fix (`~/.local/bin/lutgen-everpuccin`, rewritten 2026-09-16):** every run rebuilds `~/.config/lutgen/<theme>.txt` from the live theme's `colors.toml` (curated base16-style slot order: neutral ramp dark→light `background/color0/selection/color8/muted/dark_foreground/brown/foreground/light_foreground/bright_foreground`, then accents `green=#A7C080/cyan/blue/yellow/orange/red/magenta`, then 6 brights; fallbacks = everpuccin values) and runs **`lutgen apply -l 16 -p <theme>`** (lutgen reads the custom palette from `~/.config/lutgen/*.txt`, name = file stem). Default mode is now PURE lutgen (no blend). Flags: `--blend N` (opt-in re-dilution), `--flat` (`-N` posterize), `--level N`, `-o DIR`. Theme from `~/.local/state/omarchy/current/theme.name` (override `LUTGEN_THEME=<name>`).
- **Custom-palette gotcha (lutgen 1.1.1, lutgen-bin):** custom palettes are plain hex-per-line `.txt` files in `$LUTGEN_DIR` or `<config-dir>/lutgen` (Linux `~/.config/lutgen`); `-p everpuccin` matches the file stem, case-insensitive ('My-palette.txt' → `my-palette`). Builtins come from lutgen-palettes (base24 arrays incl. rose-pine `#21202e #191724 #403d52 #1f1d2e #524f67 #26233a #6e6a86 #908caa #9ccfd8 #31748f #ebbcba #e0def4 #c4a7e7 #eb6f92 #f6c177`; everforest-darks; catppuccin-mocha 26).
